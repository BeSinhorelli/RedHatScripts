## 📋 Sobre

Script para automação de tarefas no RHEL demonstrando conceitos de shell scripting.

### 🎯 Funcionalidades

- ✅ Estruturas de decisão (`if/else`, `case`)
- ✅ Loops (`for`, `while`)
- ✅ Tratamento de erros (`trap`, `$?`)
- ✅ Menu interativo com input do usuário
- ✅ Sistema de logging completo
- ✅ Backup automático
- ✅ Monitoramento de processos
- ✅ Criação de usuários em lote

## 🚀 Instalação

```bash
# Baixar o script
git clone https://github.com/seu-usuario/rhel-script.git
cd rhel-script

# Dar permissão
chmod +x scriptsRedHat.sh

# Executar
./scriptsRedHat.sh
